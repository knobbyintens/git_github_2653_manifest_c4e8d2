# Ingest Pipeline

This repository contains the request gateway and record validation code for
the ingest pipeline.

## Maintenance index

`docs/MAINTENANCE_INDEX.md` maps every `# [MAINT]` note in the source tree to
its exact file and line location. The index is consumed by the release checklist
and by code-review tooling, so its line numbers must stay accurate after any
structural edit to a referenced source file.

When you move code around, update the affected entries only. Entries for files
that did not change must be left exactly as they are.
